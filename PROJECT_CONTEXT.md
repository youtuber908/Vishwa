# Vishwa — Project Context

## What is Vishwa?
Vishwa is a premium interactive educational platform focused on mastery through exploration, visualization, and interaction. The initial scope (V1) is mastering India’s geography, but the architecture is designed to be universal for future modules (World geography, History, Mathematics, etc.).

## Purpose
To provide an engaging learning experience where learners achieve complete mastery through repeated, enjoyable retrieval and interaction, framed as exploration rather than traditional quizzes.

## Tech Stack (current, based on code inspection)
- **Language:** TypeScript
- **Build Tool:** Vite
- **UI Library:** React 19 with React Router DOM
- **Styling:** CSS custom properties (theme tokens) in `src/styles/global.css`
- **State Management:** React Context (ThemeProvider) + local component state; no external store yet.
- **Data Layer:** Data-driven; region definitions in TypeScript (`src/datasets/india/indiaRegions.ts`) and GeoJSON files. No formal repository layer implemented yet.
- **Mapping:** SVG-based map rendering with GeoJSON conversion scripts (in `scripts/`).
- **PWA:** Service worker registered (`src/pwa/useRegisterServiceWorker.ts`), offline fallback page.
- **Testing:** No test framework configured (`package.json` test script echoes "No tests configured").

## Current Real State (verified by code inspection)
- **App Shell:** Implemented with routing, header/footer layout, theme context.
- **Theme System:** Light/dark/theme modes persisted via localStorage; forced dark on first load.
- **India Module:**
  - Map renders SVG paths for Indian states and union territories.
  - Region selection via click/hover/keyboard (basic implementation).
  - Info panel stubbed (exists in `IndiaPage.tsx` but content limited).
- **Pages:** Home, Explore, India, Challenges, Achievements, Statistics, Settings, Help, Offline.
- **UI Components:** Button and Badge components implemented; other components (Card, Modal, Tooltip, etc.) referenced in Design-System.md not found in component library.
- **Data:** `INDIA_REGIONS` constant provides structured data (id, name, capital, facts) for each state/UT.
- **Build Outputs:** `dist/` generated by `vite build`; correctly ignored by Git.
- **Dependencies:** Includes Playwright (for testing?), world-atlas, topojson-server, d3-geo, etc.

## Known Gaps / Not Yet Implemented
- Mastery model, revision scheduler, XP/levels, achievements.
- Learning/practice engine (question types, grading, hints, feedback).
- Recommendation engine.
- Analytics/event tracking.
- Offline download management.
- Curriculum-awareness feature (NCERT/CBSE mapping) – not present in code.
- Formal data layer/repository interfaces.
- Comprehensive accessibility and performance audits.
